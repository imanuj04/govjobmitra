# GovJobMitra website starter

A responsive static website starter for GovJobMitra.

## Files
- `index.html` — homepage
- `assets/style.css` — responsive styles
- `assets/app.js` — small navigation script
- `about.html`, `privacy.html`, `disclaimer.html`, `contact.html` — starter information pages

## Deploy
Connect this repository to Cloudflare Pages. For this plain HTML/CSS/JS site:
- Framework preset: None
- Build command: leave blank
- Build output directory: `/` (or `.` if the dashboard requires a relative path)

## Before public launch
1. Add a real contact email on `contact.html`.
2. Review the privacy policy and disclaimer for the actual services used.
3. Publish only verified updates and link to official sources.
4. Add the article management/publishing workflow in a later phase.

This starter does not yet include a CMS, admin login, article database, or AI publishing automation.
